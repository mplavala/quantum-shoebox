# Quantum Shoebox: DIY & Open-Source Qubit

*A minimal, hackable open-source qubit.*

The **Quantum Shoebox** is a goal-driven, open-source project to build a minimal, room-temperature NV ensemble demonstrating the Zeeman effect and ODMR, with the longer-term goal of operation as a single qubit. The project will use affordable, mostly off-the-shelf components, housed, quite literally, in a shoebox.

The shoebox represents physical constraints, cost discipline, and an explicit rejection of unnecessary infrastructure.

The project focuses on a **single effective qubit implemented using an NV ensemble**, designed for education, experimentation, and hands-on understanding of quantum hardware. This project does not attempt to produce new physics; the goal is to reproduce key NV-center experiments using minimal open hardware. It makes no claims of quantum advantage or performance, and instead emphasizes transparency, reproducibility, and learning by building.

## What this repository contains

Documents such as a bill of materials, STL files for the optical setup, and control software will be added as development progresses.
